🎮 Tạo gamelist.js tự động

Chọn nhiều file .jar cùng lúc (giữ Ctrl để chọn nhiều). Công cụ sẽ đọc tên game, phiên bản, nhà phát hành từ trong file JAR, tự đoán kích thước màn hình (từ tên file, manifest, ảnh trong game) và loại bàn phím, rồi sinh ra file gamelist.js. Nếu manifest ghi kích thước mà player không hỗ trợ (vd 176x208), công cụ sẽ tự chọn kích thước gần đúng nhất. Bạn có thể chỉnh lại từng game trước khi tải về.

📦
Bấm để chọn file .jar hoặc kéo thả vào đây
Có thể chọn hàng chục file một lúc

Cách đoán màn hình: ① tên file có ghi kích thước (vd game-240x320.jar) → ② manifest có khai báo → ③ ảnh trong game đúng chuẩn màn hình → ④ code dùng nhiều hằng số kích thước → ⑤ mặc định 240x320. Bàn phím: manifest khai báo cảm ứng, tên file có "touch", hoặc code có xử lý chạm (pointerPressed...) thì dùng "Không phím".
